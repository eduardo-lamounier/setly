The Setly Book

Setly / Hello world

You can use println to print text into the console.

println("Hello, world!")

You can also use print to print without the newline. The following code is equivalent to the first.

print("Hello, ")
println("world!")

Running the code

Put one of the previous example in a file hello.setly. You can run the program with Setly's interpreter: setly hello.setly.

The program's output should be "Hello, world!".
