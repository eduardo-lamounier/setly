The Setly Book

Setly / Hello world

In this first chapter you'll learn how to run your first Setly program.

You can use println to print text into the console.

println("Hello, world!")

You can also use print to print without the newline. The following code is equivalent to the first.

print("Hello, ")
println("world!")

Running the code

Put one of the previous example in a file hello.setly. You can run the program with Setly's interpreter: setly hello.setly.

The program's output should be "Hello, world!".

Comments

An useful thing to also know is how to write comments. Comments are basically things you write for yourself or another programmer, rather than for the interpreter.

That means the things you see in dark-gray are valid even though they would usually result in an error without the ats.

@ This text is ignored when running
@ The at begins a line comment

@@ This right here is a command BLOCK
It spans though multiple lines
It opens and closes with two ats @@
