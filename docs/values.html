Setly / Values

Values are the data a program works with. Setly's basic data types are numbers, strings, booleans, and nil.

Numbers

Use numbers to represent quantities, like an age or a price. You can write whole numbers or use a dot for a decimal part. Put a minus sign before a number to make it negative.

println(42)
println(3.5)
println(-10)

Strings

A string represents text. Write it between double quotes, as we did with "Hello, world!" in the previous chapter. The quotes mark where the text starts and ends; they aren't part of the printed text.

Digits inside quotes are text too: "42" is a string, while 42 is a number. You can also write an empty string with "".

println("Hello, world!")
println("42")
println("") @ Prints an empty line

Booleans

A boolean has one of two values: true or false. Use booleans to represent whether something is true, like whether a player has won a game.

Comparing values also produces a boolean. Here, = checks for equality. We'll look into these operators in more detail in next chapters.

println(true)
println(false)
println(10 = 10) @ true
println(10 = 20) @ false

Nil

Use nil to represent the absence of a value. It is different from the number 0, an empty string, or false: those still represent a quantity, text, or a boolean.

println(nil)
