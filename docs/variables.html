Setly / Variables

Variables give names to changable values.

Declare a value

Use the let keyword to declare a variable. You can also use := after the variable's name to assign an initial value.

let x := 10
let y := 20

Because no value was assigned to z after declaration, it defaults to nil, which means the variable has no real value.

let z @ Equivalent to `let z := nil`

Assign another value

Assign a new value with :=. Here, x changes from a number to a string. This is valid, because Setly is a weakly typed language; it lets a variable hold any type of data.

x := "now x is a string"

Swap two variables

Assign both values together to exchange the contents of x and y.

x, y := y, x
