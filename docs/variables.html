Setly / Variables

Variables give names to fixed-type mutable values.

Declare a value

Use the let keyword to declare a variable, followed by the variable name and its type. You use := to assign the variable an initial value of that type.

let x number := 10

Assign another value

A declared variable can have its value changed by using :=, but the value must also be of the variable's type.

x := "Hello, world" @ Is invalid
x := 20 @ Is valid

Using a variable's value

By writing the variable's name were something is expected, you use that variable's value in that moment of the program.

println(x) @ Prints the value of 'x'
x := x + 1 @ Increments 'x' by one

Union types

Unions let you define multiple possible types of values for a variable. y can hold a value of type number, but it can also be nil.

let y number | nil

y := 1 @ Is valid
y := nil @ Is valid
y := "Hello" @ Is invalid
