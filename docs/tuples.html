Setly / Tuples

Tuples are used to represent a fixed-amount of values.

Declaring and defining a tuple

You write a tuple literal by putting the values in parenthesis and separated by commas.

You write a tuple type by putting the types of each position also in parenthesis and separated by commas.

let values (number, string) := (10, "abc")

Positional values of a tuple

You can use brackets after the variable to specify the position of the value you're going to change or access from a tuple.

The positions are 0-indexed (start from 0).

println(values[0]) @ prints 10
values[1] := "def" @ now holds (10, "def")

Using tuples as return values

You can make a function return a tuple to achieve returning multiple values.

Notice there's no need to put parenthesis when returning them.

fn div(a number, b number) (number, number) {
  return a / b, a % b
}

Unpacking values

When calling div, you can receive both returning values in a single line. This unpacks the returned tuple value and assigns each value to a variable.

In the above code, x will hold 3 and y will hold 1.

let x, y := div(10, 3)

@ You could also do:
let values (number, number) := div(10, 3)
let a number, b number := values...
