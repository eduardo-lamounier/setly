Setly / Loops

A loop runs a code block while a condition is true. Setly has two keywords for loops: for and while.

Loop While

while runs the code inside braces while the condition after the keyword is true.

In the following code, the message will be ru until the program is interrupted.

while true {
  print("Hello!")
}

For loop

Let's say you want to print all elements from 1 to 10. You can use a for-loop for this: i goes from 1 to 10, being incremented by one at each iteration.

Keep in mind that the loop's limit value is not included. That's why we use 11 instead of 10.

for i := 1, 11 {
  print("i: "+i)
}

You can also set a step, which default always 1 when omitted. Differently of before, the following code prints "1, 3, 5, 7, 9", since the step is set to 2.

for i := 1, 10, 2 {
  print("i: "+i)
}
