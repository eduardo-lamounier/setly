Setly / Functions

Functions define code that can be executed without re-writing it. In this chapter we'll see how functions work in Setly.

Defining a function

In this code, we define a function that prints a message into the console. This function receives a value name, which we call a parameter.

A parameter is a variable which value is assigned to it in the function call. A function can receive multiple parameters (including 0).

fn greet(name string) {
  println("Hello, ", name, "!")
}

Returning values

We can also return values. "Returning" means the function has a kind of "result" which may be useful to the caller.

In this code, the function add adds two numbers and returns the result of the addition. A function that returns something must define the returning value's type after the closing brackets of the parameters list.

fn add(x number, y number) number {
  return x + y @ Must be 'number'
}

Note that when a function receives more than one argument (parameter), they are separated by commas.

Calling a function

We can call a function by writing its name and passing the required arguments in brackets. If the function returns something, we can use this value.

greet("Eduardo") @ Will print "Hello, Eduardo!"
let n number := add(1, 2) @ Here, n will hold 3
