Setly / Functions

Functions define code that can be executed without re-writing it. In this chapter we'll see how functions work in Setly.

Defining a function

In this code, we define a function that prints a message into the console. This function receives a value name, which we call a parameter.

A parameter has a value assigned to it in the function call, and a function can receive multiple parameters (including 0).

fn greet(name) {
  println("Hello, ", name, "!")
}

Returning values

We can also return values. "Returning" means the function has a kind of "result" which may be useful to the caller.

In this code, the function add adds two numbers and returns the result of the addition.

fn add(x, y) {
  return x + y
}

Note that when a function receives more than one argument (parameter), they are separated by commas. This also applies when returning multiple values: they are separated by commas when returning.

Calling a function

We can call a function by writing its name and passing the required arguments in parentheses. If the function returns something, we can use this value - in this case, we assign it to a variable.

greet("Eduardo") @ Will print "Hello, Eduardo!"
let n := add(1, 2) @ Here, n will hold 3
