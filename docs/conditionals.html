Setly / Conditionals

An if statement chooses a block of code based on a condition. An else block handles the other case.

Check for inequality

The ~= operator compares two values for inequality. Here, x equals 10, so the else block is selected.

let x := 10

if x ~= 10 {
  println("x is not 10.")
} else {
  println("x is 10.")
}

Check for equality

Use = to compare values for equality. The condition below is true because y is 20.

let y := 20

if y = 20 {
  println("y is 20.")
} else {
  println("y is not 20.")
}

Require both conditions

Use and when both conditions must be true. Here, x must be between 1 and 10, including both limits.

Note we are using some new operators, Setly supports >, >=, <, and <= as you'd probably expect.

if x >= 1 and x <= 10 {
  println("x is between 1 and 10.")
}

Require either condition

Use or when at least one condition must be true. Here, x must be less than 1 or greater than 10.

if x < 1 or x > 10 {
  println("x is outside the range from 1 to 10.")
}

Reverse a condition

Use not to turn true into false and false into true. Here, the block is selected when x is not 10.

let isTen := x = 10
if not isTen {
  println("x is different than 10.")
}
